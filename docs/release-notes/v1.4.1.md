## What's new in 1.4.1

- **WhatsApp copes with patchy internet.** A short network drop no longer shows "Could not reach Carino's sign-in helper". An error only appears if WhatsApp can't be reached for about a minute, and messages wait and arrive when the connection is back.
- **Your linked WhatsApp stays on screen.** The Messaging screen no longer swaps your linked WhatsApp for the manual setup steps when the connection drops.
- **A new Carino number shows up by itself.** If Carino's WhatsApp number changes (for example, from Meta's test number to a real one), the app shows the new number automatically. Linked chats stay linked.
