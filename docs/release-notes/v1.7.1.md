## What's new in 1.7.1

### Fixes
- **No more "Request too large" on free AI plans.** Services like Groq's free plan accept only a few thousand tokens at a time. Carino now sends only the tools each message needs, learns each model's limit, and trims older turns when it has to, so messages fit. If a message still can't fit, Carino moves to another of your AI services or explains plainly what to do, instead of showing the service's raw error.

### Tip
- Add a free **Google Gemini** key (aistudio.google.com) in Settings → AI & connections. Its free plan takes much larger requests, and Carino uses it automatically whenever another service is too tight.
